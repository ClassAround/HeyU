# RAWCUT GLOBAL v0.1.2 — 앱 이름 변경 및 영상 재생 수정

앱 이름이 **HeyU → RAWCUT GLOBAL**로 바뀌었습니다.
그리고 앱 안에서 영상이 몇 초만 재생되다 멈추던 문제를 고쳤습니다.

## 바뀐 것

### 영상이 2초만 재생되고 멈추던 문제 (수정)

미리보기와 결과 영상이 초반만 재생되고 멈췄으며, 탐색(seek)도 되지 않았습니다.

앱 내부의 영상 전송이 **HTTP Range 요청을 처리하지 않던 것**이 원인이었습니다.
브라우저는 영상을 구간 단위로 요청하면서 재생하는데, 서버가 `206 Partial Content`를
돌려주지 못하면 첫 응답 이후를 이어받을 방법이 없습니다. 파일이 클수록 증상이 뚜렷했습니다.

이제 구간 요청을 정상 처리합니다. 파일 끝에서부터 읽는 요청(`bytes=-N`)도 지원하며,
이는 MP4 메타데이터가 파일 끝에 있는 영상에서 실제로 사용됩니다.

### 앱 이름 변경

화면 표시, 창 제목, 로그인 완료 페이지, 결과 저장 폴더, 설치 파일 이름이 모두 바뀌었습니다.

**기존 설정은 자동으로 이전됩니다.** 앱 이름이 바뀌면 저장 경로도 바뀌기 때문에
그대로 두면 Google 로그인과 HeyGen 연결이 초기화됩니다. 처음 실행할 때 이전 설정을
새 위치로 복사하므로 다시 로그인할 필요가 없습니다.

- 결과 저장 위치: `~/Movies/HeyU` → `~/Movies/RAWCUT GLOBAL` (기존 결과물 포함)
- 이전 설정은 복사되며 지워지지 않습니다.

## 다운로드

- Apple Silicon Mac (M 시리즈): `RAWCUT-GLOBAL-0.1.2-arm64.dmg`
- Intel Mac: `RAWCUT-GLOBAL-0.1.2-x64.dmg`
- Windows (Intel/AMD 64비트): `RAWCUT-GLOBAL-0.1.2-x64.exe`

`SHA256SUMS-v0.1.2.txt`로 다운로드 파일의 체크섬을 확인할 수 있습니다.

## Mac 설치

1. 실행 중인 앱을 종료합니다.
2. 새 DMG를 열고 **RAWCUT GLOBAL**을 Applications(응용 프로그램)에 복사합니다.
3. 이전 **HeyU** 앱은 더 이상 사용하지 않으므로 삭제해도 됩니다. 설정은 이미 복사되었습니다.
4. 확인되지 않은 개발자 안내로 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를
   선택합니다. 이 저장소에서 받은 파일인지 확인한 후 허용하세요.

이 버전은 **Apple Developer ID 서명 및 공증을 받지 않은 테스트 빌드**입니다.
ad-hoc 서명은 앱 내부의 무결성을 확인하며 개발자 신원이나 Apple 승인을 보증하지 않습니다.
보안 설정을 전역으로 끄지 마세요.

Windows는 EXE를 실행해 설치합니다. 코드 서명이 없어 보안 경고가 표시될 수 있습니다.

## 검증

- 타입 검사 및 프로덕션 빌드 통과.
- 자동 테스트 15개 통과. Range 요청 해석에 대한 테스트 6개를 새로 추가했습니다
  (전체 응답, 열린 구간, 범위 초과 시 잘라내기, 끝에서부터 읽기, 불가능한 구간).
- 설정 자동 이전을 실제로 확인했습니다. 이름 변경 후에도 로그인과 HeyGen 연결이 유지됩니다.
- 실제 더빙 1건이 처음으로 끝까지 성공했습니다(업로드 → 번역 → 결과 저장).

## 아직 확인하지 못한 것

- 다른 Mac에서의 Gatekeeper 최초 실행 절차.
- Windows 설치 파일은 macOS에서 크로스 빌드했습니다. 실제 Windows에서의 설치·실행 검증이 필요합니다.
- 이름 변경 후 설정 이전은 이 개발 환경에서만 확인했습니다. 설치된 앱(패키지 빌드)에서의
  이전은 이번 릴리즈를 설치하며 확인해야 합니다.
