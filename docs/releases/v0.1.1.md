# HeyU v0.1.1 — Mac 서명 수정

v0.1.0 Mac 앱에 남아 있던 유효하지 않은 Electron 서명을 수정했습니다.
앱과 내부 실행 파일을 ad-hoc 서명하고, 빌드 중 엄격한 서명 검증을 수행합니다.

## 다운로드

- Apple Silicon Mac (M 시리즈): `HeyU-0.1.1-arm64.dmg`
- Intel Mac: `HeyU-0.1.1-x64.dmg`
- Windows는 이번 수정 대상이 아닙니다. [v0.1.0 설치 파일](https://github.com/ClassAround/HeyU/releases/tag/v0.1.0)을 사용하세요.

## Mac 설치

1. 실행 중인 HeyU를 종료합니다.
2. 새 DMG를 열고 HeyU를 Applications(응용 프로그램)에 복사해 이전 앱을 교체합니다.
3. 응용 프로그램 폴더에서 HeyU를 실행합니다.
4. 확인되지 않은 개발자 안내로 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택합니다. 이 저장소에서 받은 파일인지 확인한 후 허용하세요.

이 버전은 **Apple Developer ID 서명 및 공증을 받지 않은 테스트 빌드**입니다.
ad-hoc 서명은 앱 내부의 무결성을 확인하며 개발자 신원이나 Apple 승인을 보증하지 않습니다.
다른 Mac에서의 설치와 최초 실행은 추가 확인이 필요합니다.
보안 설정을 전역으로 끄지 마세요. 계속 ‘손상됨’이 나오면 macOS 버전과 Mac 칩 종류를 알려주세요.

Google 로그인과 HeyGen 연결, 더빙 사용 방법은 v0.1.0과 같습니다.
`SHA256SUMS-v0.1.1.txt`로 다운로드 파일의 체크섬을 확인할 수 있습니다.

## 검증

- 타입 검사 및 프로덕션 빌드 통과.
- 두 DMG의 체크섬 및 마운트한 앱의 `codesign --verify --deep --strict` 검사 통과.
- Apple Silicon DMG 안의 앱이 별도 테스트 프로필에서 10초간 실행 상태를 유지하는 것 확인.
- 다른 Mac의 Gatekeeper 최초 실행 허용 절차는 아직 확인하지 못했습니다.
