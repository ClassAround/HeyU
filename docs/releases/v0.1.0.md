# HeyU v0.1.0 — 설치 테스트용

> **Mac 사용자는 [v0.1.1](https://github.com/ClassAround/HeyU/releases/tag/v0.1.1)을 받으세요.**
> v0.1.0 Mac 앱의 서명 오류로 ‘손상되어 열 수 없음’이 발생할 수 있어 수정했습니다.
> Windows 설치 파일은 이 릴리스를 계속 사용합니다.

Google 로그인과 HeyGen 계정 연결 후 영상을 선택하면 영어 립싱크 더빙을 실행합니다.
ChatGPT 로그인, 채팅, OpenAI API 키는 필요하지 않습니다.

## 다운로드

| 환경 | 파일 |
|---|---|
| Windows (Intel/AMD 64비트) | `HeyU-0.1.0-x64.exe` |
| Mac (Apple Silicon: M 시리즈) | `HeyU-0.1.0-arm64.dmg` |
| Mac (Intel) | `HeyU-0.1.0-x64.dmg` |

macOS는 DMG를 열어 HeyU를 Applications에 복사합니다.
Windows는 EXE 설치 프로그램을 실행해 설치 위치를 선택합니다.
이번 파일은 코드 서명·Apple 공증이 없는 테스트 빌드이므로 OS 보안 경고가 표시될 수 있습니다.

## 테스트 순서

1. 앱 실행 → 허용된 Google 계정으로 로그인합니다.
2. HeyGen 계정을 연결합니다. 로그인 정보는 각 PC에 별도로 저장됩니다.
3. 짧은 영상을 선택하고 더빙 옵션을 확인합니다.
4. **영어로 더빙하기**를 실행합니다. 실제 생성에는 HeyGen 웹 플랜의 MCP 크레딧이 사용됩니다.
5. 업로드·번역·다운로드 진행 상태와 완료 후 영상·음성 재생을 확인합니다.
6. **폴더에서 보기**로 저장된 MP4를 열어 확인합니다.
7. 앱을 종료하고 다시 열어 로그인 유지와 최근 결과 표시를 확인합니다.

## 주요 변경

- 앱이 HeyGen MCP를 직접 호출해 업로드·더빙·결과 조회를 수행합니다.
- ChatGPT 로그인과 채팅, OpenAI API 키 경로를 제거했습니다.
- 다운로드는 임시 파일에 저장하고 크기·MP4 구조를 검사한 뒤 완료 처리합니다.
- 진행 중인 번역 ID를 저장해 앱 재실행 시 조회를 이어갑니다.

## 검증 범위

- 타입 검사, 프로덕션 빌드, 자동 테스트 9개 통과.
- Apple Silicon 및 Intel DMG 이미지 체크섬 검사 통과.
- Windows 설치 파일은 macOS에서 크로스 빌드했습니다. 실제 Windows 설치·실행 검증은 필요합니다.
- 실제 다른 Mac에서의 설치·권한·로그인 검증은 필요합니다.

`SHA256SUMS.txt`로 다운로드 파일의 체크섬을 비교할 수 있습니다.
